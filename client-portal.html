Create a Supervisely project

Creates a new image project in Savannah's Supervisely workspace and adds its access link to the selected client account in this portal. Leave Client account UUID blank to create a test project under your administrator account.

Configure the client's annotation tool

Choose whether Savannah provides the workspace or the client uses their own platform. For client-owned tools, add the platform name and secure workspace link. Only administrators can change these settings.

BYOT access is granted by the client in their own platform. Savannah will not ask for or store the client's platform password or API key.

CVAT connection

Check that Savannah can securely connect to your CVAT workspace. This test only reads the task list and does not create or change CVAT tasks.

Create a CVAT sample task

Create a Savannah-managed CVAT task using one sample image. The image is sent securely from this page to CVAT through Savannah's server. Only JPEG, PNG or WebP files up to 20 MB are accepted. Do not use client data for this test.

The first test task uses one label named “object”. You can change labels later when we configure the real annotation workflow.

Upload completed deliverables

Upload completed annotation exports or project documents. The selected project's client will be able to access the files in their Deliverables section. Maximum file size: 100 MB.

Manage annotators

Annotators first create a Savannah account using the sign-up tab. Enter their registered email below to activate annotator access. They must sign out and back in after activation.

Assign a project

Assignments grant portal visibility only. The annotator must also be invited into the relevant Supervisely, CVAT or client-owned workspace with their own account.
